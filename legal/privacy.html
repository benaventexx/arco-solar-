Política de Privacidade

Última atualização: 2026.

O que guardamos

O Arco Solar guarda o tipo de pele, o FPS escolhido, o idioma, a última cidade pesquisada e o histórico de sessões de exposição solar apenas no teu dispositivo (armazenamento local do navegador). Nada disto é enviado para nenhum servidor nosso — na verdade, esta app não tem servidor nem base de dados própria.

Dados de localização

Quando pesquisas uma cidade ou usas o GPS, a latitude/longitude é enviada diretamente ao Open-Meteo (serviço meteorológico público) apenas para obter o índice UV dessa localização. Não guardamos essa informação em servidores próprios nem a associamos à tua identidade.

Serviços de terceiros

Usamos a API pública e gratuita do Open-Meteo (open-meteo.com) para obter dados de UV. Consulta a política de privacidade deles para saber como tratam os pedidos recebidos.

Apagar os teus dados

Podes apagar todos os dados guardados a qualquer momento limpando os dados do site nas definições do teu navegador, ou desinstalando a app caso a tenhas adicionado ao ecrã principal.

Contacto

Para questões sobre privacidade, contacta o autor da app diretamente.
